# Jubelle application icon

These files hold the approved Jubelle icon. The upstream file names (MS4_AppIcon_*) are kept
so every existing build and installer reference keeps working unchanged.

- Source artwork: the approved circular Jubelle icon (kept unaltered outside the repository).
- Square version: the circle is placed on a square canvas and the four corners are filled with
  the circle's own charcoal (#1A1A23), so it reads as one seamless square. Every pixel of the
  circle is identical to the approved artwork.
- AppIcon.icon (macOS Icon Composer): solid charcoal fill, the square artwork as a single layer,
  glass, specular highlight, shadow and translucency all turned off.
